# sveltekit on bun

Пример sveltekit на bun для Timeweb Cloud Apps.

## Параметры деплоя

| Параметр | Значение |
| --- | --- |
| Runtime | `bun` |
| Фреймворк в API | `sveltekit` |
| Тип приложения | `frontend` |
| Команда сборки | `bun run build` |
| Директория сборки | `build` |

## Локальный запуск

```bash
bun install
bun run build
```
